# S3 : explorateur de buckets

[← Sommaire](README.md)

Pour les S3 **d'entreprise** compatibles (MinIO, Ceph, NetApp StorageGRID, Scality…), pas pour
AWS.

## Créer la connexion

**+** → **S3**, puis :

| Champ                             | Valeur                                                                                             |
| --------------------------------- | -------------------------------------------------------------------------------------------------- |
| **URL du S3**                     | L'URL principale, par ex. `https://s3.intra`                                                       |
| **Clé d'accès** / **Clé secrète** | La clé secrète est chiffrée par Windows                                                            |
| **Région**                        | Facultative (`us-east-1` par défaut)                                                               |
| **Path-style**                    | Coché par défaut (`https://s3.intra/bucket/clé`), ce qui convient à la plupart des S3 d'entreprise |
| **Buckets en plus**               | Buckets à afficher même si votre clé n'a pas le droit de **lister** les buckets                    |
| **Certificat**                    | Comme pour Rancher : autorités Windows, fichier `.cer`, ou vérification ignorée                    |

**Tester la connexion** liste les buckets. Si votre clé n'a pas le droit de les lister, le
test vérifie l'accès au premier bucket saisi dans **Buckets en plus**.

## Explorer

Cliquez sur un bucket : un onglet **explorateur** s'ouvre.

- **Fil d'Ariane** en haut : cliquez sur un niveau pour y remonter. **📁 ..** ou
  **Retour arrière** remonte d'un dossier.
- **Tri** : cliquez sur les en-têtes **Nom**, **Taille** ou **Modifié le**. Les dossiers
  restent en tête et les noms sont triés naturellement (`f2` avant `f10`).
- **Rechercher (début du nom)** : filtre le dossier courant par préfixe, côté serveur, donc
  efficace même sur des millions d'objets.
- Les dossiers de plus de 1 000 éléments se chargent par pages : bouton
  **Charger les 1 000 suivants**.

## Aperçu

Cliquez sur un fichier pour l'afficher à droite :

- **Texte** coloré : JSON (indenté automatiquement), XML, YAML, logs, CSV… avec recherche
  **Ctrl+F**.
- **`.gz`** : décompressé à la volée.
- **Images** : PNG, JPEG, GIF, WebP, SVG…
- Pour les gros fichiers, seuls les **5 premiers Mo** sont affichés : téléchargez le fichier
  pour tout voir.

## Actions

Cochez un ou plusieurs éléments pour faire apparaître les actions :

| Action                                    | Détail                                                                                                                                                                        |
| ----------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **↓ Télécharger**                         | Un fichier : boîte « Enregistrer sous ». Plusieurs éléments ou un dossier : choix d'un dossier local, contenu téléchargé récursivement                                        |
| **↑ Envoyer des fichiers… / un dossier…** | Dans le dossier courant. Vous pouvez aussi **glisser-déposer** des fichiers ou des dossiers depuis l'Explorateur Windows. Les gros fichiers sont envoyés en plusieurs parties |
| **Renommer** (**F2**)                     | Fichier ou dossier. S3 n'ayant pas de renommage, Ocekour copie puis supprime, récursivement pour un dossier                                                                   |
| **Supprimer** (**Suppr**)                 | Fichiers et dossiers, récursivement, **après confirmation** qui indique le nombre d'objets concernés                                                                          |
| **Copier le chemin**                      | Copie l'adresse `s3://bucket/chemin`                                                                                                                                          |

Les opérations longues s'affichent en bas de l'onglet, avec leur progression et un bouton
**Annuler**.

> ⚠️ La suppression est **définitive** (Ocekour ne gère pas les versions d'objets).
